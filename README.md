
**Fraud Detection Analytics**

 **Project Overview**
This project focuses on analyzing financial transactions to identify fraudulent activities and understand transaction patterns using data analytics. The objective is to distinguish fraudulent transactions from legitimate ones, identify high-risk transaction types, and generate meaningful insights that can support fraud prevention and risk management.

**Objectives**
- Analyze transaction data to understand fraud patterns.
- Identify fraudulent transactions based on transaction types and amounts.
- Calculate fraud rates and compare fraudulent versus legitimate transactions.
- Examine account balance changes and identify suspicious transaction behavior.
- Present key findings through an interactive Power BI dashboard.

Tools & Technologies
- **Python:** 
- **Pandas & NumPy:**.
- **DAX**
- **Power BI**.

 **Key Analysis Areas**
- Total transactions and total transaction amount.
- Fraudulent transactions and fraud rate.
- Transaction type-wise fraud analysis.
- Fraud patterns based on transaction amounts.
- Comparison of fraudulent and legitimate transactions.
- Identification of suspicious account balance movements.

 **Key Insights**
The analysis explores which transaction types contribute most to fraudulent activities, how fraudulent transactions differ from legitimate transactions, and whether unusual transaction amounts or account balance changes indicate potential fraud risks.

 **Business Impact**
This project demonstrates how data analytics can help financial institutions monitor transaction behavior, identify suspicious patterns, and make data-driven decisions to improve fraud detection and reduce financial losses.

**Conclusion**
The project combines Python, SQL Server, and Power BI to transform raw financial transaction data into actionable insights, demonstrating practical skills in exploratory data analysis, database querying, and business intelligence reporting.
